# CF7 HTML & CSS Exercises

Αυτό το repository περιέχει ασκήσεις HTML και CSS που υλοποιήθηκαν στο πλαίσιο του Coding Factory 7 (ΟΠΑ).

## 📁 Δομή

- `chapter-1` έως `chapter-7`: Βασικά και προχωρημένα concepts HTML/CSS ανά ενότητα
- `chapter-bootstrap`: Εισαγωγή σε Bootstrap
- `chapter-tailwind`: Βασική χρήση Tailwind CSS
- `html-css-exercises`: Ασκήσεις τελικής εξάσκησης
- `apps/form.html`: Εφαρμογή με HTML φόρμα
- `dashboard.html`, `test.html`: Πρόσθετες ανεξάρτητες δοκιμές

## ✅ Σκοπός

Το repository χρησιμοποιείται για εξάσκηση, δοκιμές και παρουσίαση των βασικών γνώσεων HTML, CSS και UI frameworks.
